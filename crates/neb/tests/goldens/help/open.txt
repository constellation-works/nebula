Deprecated alias for `review --short`, kept for one release so existing routines keep working. Hidden from `--help`

Usage: neb open [OPTIONS]

Options:
      --root <DIR>  Corpus location. Defaults to `$NEBULA_ROOT`, else the corpus the current directory is in, else `~/.config/nebula/root`, else `~/.nebula`
      --tag <TAG>   Only nodes carrying this tag. Repeat to require every one
      --json        Emit JSON instead of text, for scripts and agents
  -h, --help        Print help
